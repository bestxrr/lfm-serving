# LFM2.5-350M BF16/FP8 Draft REP30 Comparison

Date: 2026-07-30

Evidence label: LOCAL-CONTENDED-PAIRED. Absolute latency does not transfer to
H200, but contention was invariant across all four timing arms.

| BF16 draft | 0/30 | 8.47 | 293.80 ms | 62.63 / 72.68 ms | 99.50 s | 8,634 MiB |

The baseline TPOT anchors differ by only 0.32%. BF16 draft regresses TPOT by
approximately 354%, and FP8 draft by approximately 360%, far outside the
intra-session noise band.

## Speculation counters

| Draft | Accepted/drafted | Acceptance | Effective tokens/step |
|---|---:|---:|---:|
| BF16 | 3,162 / 5,316 | 59.48% | 1.595 |
| FP8 | 3,178 / 5,714 | 55.62% | 1.556 |

FP8 saves 150 MiB peak VRAM but does not reduce TPOT. It also loses 3.86
percentage points of acceptance, so it is strictly worse than the BF16 draft
for this workload.

## Contention control

Every arm observed:

- 100.0% average total GPU utilization;
- exactly 54,337 MiB external VRAM;
- exactly 1,755 MHz average SM clock;
- 249.5-250.0 W average power.

The large draft regression is therefore a credible directional result despite
the shared GPU.

## Runtime fixes discovered

The first BF16 draft attempt exposed a capacity-vs-active-row bug at
`max_num_seqs=8`: group block tables retained eight rows while query metadata
contained five active requests. Slicing group block tables to the active
request count fixed the crash. The corrected runtime completed both draft
arms with zero errors.

FP8 draft additionally required preserving the target's
`QuantizationConfigArgs` when constructing the draft `VllmConfig`; this was
used for the local experiment only.

## Verdict

**REJECT both 350M draft variants for ERS optimization.**

The 59% acceptance is sufficient in isolation, but the full 350M forward and
verification overhead dominates the saved target steps. Online FP8 packaging
does not repair the economics. Keep the generic hybrid-draft correctness patch
as engineering work, but do not spend an official slot on this proposer.

The best tested configuration in this campaign remains the non-speculative
FP8 per-tensor baseline.
